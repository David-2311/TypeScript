# Guía de Ejercicios de Machine Learning - SENA

Proyecto con 7 ejercicios prácticos de Machine Learning usando Python y Scikit-Learn.

## Instalación

1. Abrir la carpeta del proyecto en la terminal:

```bash
cd "D:\TypeScript\Machine learning"
```

2. Instalar las dependencias:

```bash
pip install -r requirements.txt
```

## Ejecución de los ejercicios

Para ejecutar un ejercicio individual:

```bash
python ejercicio_1_regresion.py
python ejercicio_2_clasificacion.py
python ejercicio_3_clustering.py
python ejercicio_4_rl_grid6x6.py
python ejercicio_5_chatbot_intents.py
python ejercicio_6_chatbot_soporte.py
python ejercicio_7_rl_laberinto.py
```

## Ejercicios

| Ejercicio | Tipo de ML | Algoritmo | Archivo | Dataset |
|-----------|-----------|-----------|---------|---------|
| Ejercicio 1 | Regresión | LinearRegression | `ejercicio_1_regresion.py` | `housing_regression_dataset.csv` |
| Ejercicio 2 | Clasificación | DecisionTreeClassifier | `ejercicio_2_clasificacion.py` | `student_classification_dataset.csv` |
| Ejercicio 3 | Clustering | KMeans | `ejercicio_3_clustering.py` | `customer_clustering_dataset.csv` |
| Ejercicio 4 | Aprendizaje por Refuerzo | Q-Learning | `ejercicio_4_rl_grid6x6.py` | (cuadrícula 6x6) |
| Ejercicio 5 | Procesamiento de Lenguaje Natural | TF-IDF + Naive Bayes | `ejercicio_5_chatbot_intents.py` | `chatbot_intents_dataset.csv` |
| Ejercicio 6 | Procesamiento de Lenguaje Natural | TF-IDF + Naive Bayes | `ejercicio_6_chatbot_soporte.py` | `tech_support_dataset.csv` |
| Ejercicio 7 | Aprendizaje por Refuerzo | Q-Learning | `ejercicio_7_rl_laberinto.py` | (laberinto especial) |

## Tecnologías utilizadas

- Python 3
- scikit-learn (modelos de ML)
- pandas (manejo de datos)
- numpy (operaciones numéricas)
- matplotlib (visualización)
