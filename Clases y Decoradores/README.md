# Ejercicios Prácticos - Clases y Decoradores en TypeScript

Proyecto con 11 ejercicios prácticos para la clase de SENA sobre Clases y Decoradores en TypeScript.

## Instalación

1. Abrir la carpeta del proyecto en la terminal:

```bash
cd "D:\TypeScript\Clases y Decoradores"
```

2. Instalar las dependencias:

```bash
npm install
```

## Ejecución de los ejercicios

Para ejecutar un ejercicio individual:

```bash
npx ts-node src/ejercicio01.ts
```

O usar los scripts definidos en package.json:

```bash
npm run ejercicio01
npm run ejercicio02
...
npm run ejercicio11
```

## Ejercicios

| Ejercicio | Concepto | Descripción |
|-----------|----------|-------------|
| Ejercicio 1 | Clases y métodos | Clase Producto con cálculo de inventario |
| Ejercicio 2 | Modificadores de acceso | Clase Usuario con private, public, readonly |

| Ejercicio 4 | Herencia | Vehiculo, Automovil y Motocicleta con extends y super |
| Ejercicio 5 | Herencia y métodos | Empleado con cálculo de salario diferente |
| Ejercicio 6 | Interfaces | DispositivoElectronico con implements |

| Ejercicio 8 | Interfaces | Interfaz Estudiante con implementación |
| Ejercicio 9 | Decoradores | Decorador que agrega propiedad fechaCreacion |

| Ejercicio 11 | Decoradores de métodos | Decorador que registra nombre y parámetros |

## Tecnologías utilizadas

- TypeScript
- Clases y constructores
- Modificadores de acceso (public, private, readonly)
- Herencia (extends, super)
- Interfaces (implements)
- Decoradores (@Decorador)
- experimentalDecorators en tsconfig.json
